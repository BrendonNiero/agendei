# Projeto de Agendamento Fullstack

Este é um projeto de agendamento desenvolvido com Blazor Server, PostgreSQL e ASP.NET Identity, permitindo que usuários se cadastrem, façam login e gerenciem horários de eventos.

## Funcionalidades

Cadastro de usuários com ASP.NET Identity

Autenticação e autorização (login/logout, níveis de acesso)

CRUD de agendamentos (criar, visualizar, editar, excluir)

Visualização de agenda em calendário

Painel administrativo para gerenciamento de usuários e horários

## Tecnologias Utilizadas

Frontend & Backend: Blazor Server (.NET 8)

Autenticação: ASP.NET Core Identity

Banco de Dados: PostgreSQL

Migrations: EF Core Migrations

ORM: Entity Framework Core

Containerização (opcional): Docker
